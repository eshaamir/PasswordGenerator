 <h1>Password Generator</h1>
    <p>
        This is a customizable password generator website built using <strong>React</strong> and styled with <strong>TailwindCSS</strong>. Users can generate secure random passwords with options to include numbers, special characters, and customize the length as per their preferences. This tool provides an easy and intuitive interface to create strong passwords, enhancing security for everyday use.
    </p>
    <h2>Features:</h2>
    <ul>
        <li><strong>Custom Length</strong>: Choose the desired length of the password.</li>
        <li><strong>Character Inclusion</strong>: Option to include numbers, special characters, or just letters.</li>
        <li><strong>Real-time Preview</strong>: Instantly see the generated password as you configure settings.</li>
        <li><strong>Responsive Design</strong>: Fully responsive interface, designed to work seamlessly on all devices.</li>
    </ul>
    <h2>Technologies Used:</h2>
    <ul>
        <li><strong>React</strong> for creating an interactive UI.</li>
        <li><strong>TailwindCSS</strong> for a clean and responsive design.</li>
    </ul>
